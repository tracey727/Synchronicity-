# Synchronicity App — GitHub + Vercel

Static single-page app package.

## GitHub
Upload the contents of this folder to the repository root. `index.html` is the app entry point.

## Vercel
Import the GitHub repository into Vercel. No build command is required. The app is served directly from the repository root.

## Files
- `index.html` — app
- `vercel.json` — Vercel static-site settings
- `README.md` — deployment notes
